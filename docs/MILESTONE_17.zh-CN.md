# Milestone 17：设置分组、中文界面与预设

日期：2026-11-13。分支：`codex/milestone-17-settings-profiles`。
基线：M16 提交 `581ffa86d0800b70cdab2d486a65606b2bc9e160`。
[English version](MILESTONE_17.md)。

M17 让已有功能更容易查找和配置，加入完整简体中文标签与三种范围明确的预设。
GLSL 源码和着色器默认值不变。
Minecraft 中菜单布局和预设交互仍未观察；实际执行的验证另行记录。

## 1. 从首页预设选择器开始

打开 AuroraShader 的**光影包设置**，在首页选择预设，再通过 Iris 应用待生效的设置。
需要微调时进入下方分组。选择预设只改变它控制的六项；
其余 45 项，包括调色、雾、曝光、调试和场景管线，保留当前值。

在 Minecraft 语言设置中选择简体中文，再重新打开光影设置，即可使用中文标签。
`shaders/lang/zh_cn.lang` 与 `en_us.lang` 有相同的 159 个键，以 UTF-8 保存。
Iris 按 UTF-8 读取光影语言文件。
[语言加载实现](https://github.com/IrisShaders/Iris/blob/99d855970316329f2e0e42ac2b79ef763cb77cc3/common/src/main/java/net/irisshaders/iris/shaderpack/LanguageMap.java)。

| 分组 | 在这里找什么 |
|---|---|
| Aurora 天空与光色 | 天空配色/混合、阳光/环境光颜色、定向光系数 |
| 阴影 | 开关、硬阴影/PCF/Poisson、柔和度与偏移 |
| 水面颜色与天空反射 | 水面风格/色调/反射、法线波动与水深颜色 |
| 云颜色与大气 | 原生云风格、色调与雾 |
| Aurora 夜空光带 | 夜空极光开关、强度与运动 |
| 受控泛光 | 开关、强度、阈值与柔和过渡 |
| 距离与高度雾 | 开关、密度、近处清晰距离、参考高度、高度尺度与雨天增雾 |
| 调色 | 曝光、饱和度、对比度、冷暖、绿/洋红色调与灰度 |
| 高级与调试 | 调试视图；进入“场景颜色与高光”调整管线/高光映射 |

51 个选项均显式放置一次。曝光现在只出现在“调色”中；
场景存储/高光映射放在“高级与调试”下，没有删除或重命名选项。
子菜单与预设选择器使用 Iris 已有设置语法。
[设置语法](https://shaders.properties/current/reference/shadersproperties/shader_settings/)。

## 2. 预设恰好控制六项

| 选项 | 轻量 | 均衡（默认） | 柔和阴影 |
|---|---|---|---|
| `SHADOWS_ENABLED` | 开 | 开 | 开 |
| `SHADOW_FILTER` | 0：硬阴影 | 1：3x3 PCF | 2：5x5 PCF |
| `BLOOM_ENABLED` | 0 | 1 | 1 |
| `AURORA_ENABLED` | 0 | 1 | 1 |
| `WATER_WAVES` | 0 | 1 | 1 |
| `WATER_DEPTH_TINT` | 0 | 1 | 1 |

均衡与这六项已有源码默认值一致。
轻量继承均衡，再改变阴影过滤和四个可选效果；柔和阴影继承均衡，只改变阴影过滤。
预设继承是 Iris 原有能力。
[预设解析](https://github.com/IrisShaders/Iris/blob/99d855970316329f2e0e42ac2b79ef763cb77cc3/common/src/main/java/net/irisshaders/iris/shaderpack/option/ProfileSet.java)。

“默认”不是完整设置重置。新增预设不会自动应用均衡，也不会替换已有保存配置。
选择均衡恢复这六项，同时保留艺术化选择，包括已经保存的零强度。

## 3. 手动修改后，预设标签怎样变化

Iris 只比较预设列出的选项值。手动修改可能匹配另一个预设；
只有没有任何预设匹配时，才显示 **Custom／自定义**。
修改六项之外的选项，不会强制变成自定义。
[匹配逻辑](https://github.com/IrisShaders/Iris/blob/99d855970316329f2e0e42ac2b79ef763cb77cc3/common/src/main/java/net/irisshaders/iris/shaderpack/option/Profile.java)。

| 从均衡开始，只修改…… | 匹配标签 |
|---|---|
| 曝光或雾密度 | 均衡 |
| 阴影过滤改为 5x5 PCF | 柔和阴影 |
| 泛光改为关 | 自定义 |
| 阴影改为关 | 自定义；三个命名预设都启用阴影 |

匹配标签描述设置，不代表画面必定显示对应效果。
旧场景模式、调试视图、环境条件、零强度或关闭的上级风格，仍可独立抑制已启用功能。
例如之前关闭了独立的 Aurora 天空选项，选择均衡并不会把它重新打开。

选择器共用提示键 `profile.comment`；
名称分别使用 `profile.BALANCED`、`profile.LIGHT` 和 `profile.SOFT_SHADOWS`。
该控件不使用单个预设的 `profile.NAME.comment`。
[预设控件](https://github.com/IrisShaders/Iris/blob/99d855970316329f2e0e42ac2b79ef763cb77cc3/common/src/main/java/net/irisshaders/iris/gui/element/widget/ProfileElementWidget.java)。

## 4. 这些名称意味着哪些成本变化

对于范围内、实际参与的接收点，柔和度非零时，硬阴影、3x3 和 5x5 分别进行
1、9、25 次阴影深度比较。柔和度为零时走已有硬阴影捷径。
三个预设都保留 2048 阴影贴图和 64 格投射距离设置；轻量不会取消阴影贴图绘制。

关闭泛光会跳过其视觉贡献，但四个全屏阶段与半分辨率临时缓冲仍保留。
关闭极光、波浪法线和水深颜色，会跳过原本有效路径上的相应可选运算。
这些变化不能直接证明 FPS 提升或某个硬件档位已经验证，本阶段没有耗时结论。

预设保留原生水面 alpha 与合成；“水深颜色”仍是竖直背景间距启发式，不是吸收。
冷暖色调仍是艺术化调节，不是物理开尔文温度。这些含义在中文提示中继续保留。

## 6. 四个有用区别

1. **预设与重置：** 预设应用指定子集，不是整个配置。
2. **标签与画面：** 选项匹配不会覆盖功能的其他条件。
3. **关闭功能与零成本：** 视觉回退后，已分配的阶段/缓冲仍可能存在。
4. **翻译键一致与界面实测：** 键一致能避免遗漏，布局仍需观察。
