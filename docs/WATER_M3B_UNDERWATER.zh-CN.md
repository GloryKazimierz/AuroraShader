# M3B：实际可见有限水面的水下出口

状态：默认关闭的开发模块。最终实际 OpenGL 生产器/合成测试、完整 CPU 检查及针对性离线编译全部通过；没有声称已在 Minecraft/Iris 中完成运行验收。

`WATER_UNDERWATER=0 [0 1]` 需要水体光学、已有的独立缓冲混合能力和屏幕反射。在「水面 / 倒影（高）」和「水面 / 焦散（极致）」中开启。**不增加任何图像缓冲或纹理分配**：7号仍记录过滤后的向上观察空间法线与原始深度，8号 alpha 的 byte1标记出水界面；红通道继续独立累计水层与遮挡物。原有水上光学和泡沫会拒绝非零 alpha。不占用11/12号。

## 实际实现

生产器只接管真实可见、接近水平的单层顶面出口。镜头必须在水中，界面位于观察射线的上方，并通过原始最终深度核对。原生颜色和 alpha 不变；玻璃、多层水、前景覆盖、侧壁、真实底面、缺失深度、未知混合、岩浆、封顶维度及视觉负面效果均保持原有渲染。

只读核对安装的 Sodium0.8.4 与 Iris1.10.5 后发现：Sodium 会反转顶面背侧的顶点次序，而 Iris 按次序重新计算法线。不能只接受正Y法线。因此先由 `0.5-at_midBlock.y/64` 判断顶点在方块中的高度，排除低于等于1/16方块的真实底面，再把正负两种顶面法线统一向上。新增的高度 varying 仅在功能启用时存在。

物理核心计算 Snell 折射、精确非偏振 Fresnel、全反射与辐亮度折射率平方系数。共享折射率1.333，对应水到空气临界角约48.6066度。全反射没有空气透射方向；在确认命中的置信范围内，任意非零反射强度都采用 F=1，零表示明确关闭并回退原生。非全反射仍保留艺术强度控制。

空气透射和水中反射使用已有有界屏幕射线及配对 W1 辐亮度/深度。目标还需有效方向光份额标记和明确的透明归属。空气命中必须在实际界面上方，反射目标必须在下方。反射段的垂直投影逐像素核对已捕获的有限顶面，最多128格，不能越过缺失水面或不一致高度。这是屏幕采样证据，不是不可见池壁与所有流体体积的重建。

仅已确认的水中路径应用 Beer 消光与受现有光源约束的散射，黑色光源不会产生自发光。不拿水下摄像机的蓝色雾当作空气雾，也不猜测未知的太阳入水路径。alpha 保持原值，泡沫历史拒绝出口归属，原有 bloom 只执行一次。

## 必须保留的边界

这**不是完整水下渲染，也没有重建近裁剪水线**。顶面被近裁面裁掉后没有可观测出口，相关像素保留原生水体，而不是填入假设的无限平面。在测试水池的-1厘米位置仍有少量顶面像素，但没有完整可接管光路；-1毫米时顶面已完全被近裁。测试记录了这种回退，不能称为已解决水线。玩家脚部状态不能替代逐像素界面。

未提交的洞穴背面、屏幕外信息、射线未命中、侧向出口、陡峭流动和未知体积均保留原生。全反射缺少目标数据时也会保留原生近似，不能声称已经重建正确反射。当前不含硬件光追、流体模拟、顶点位移、完整体积散射或独立水下天空。最坏可有两条场景射线加有限覆盖遍历，性能尚未计时，默认关闭。
