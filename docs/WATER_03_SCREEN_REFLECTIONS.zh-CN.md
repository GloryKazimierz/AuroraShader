# Water 03：有范围限制的水面屏幕空间反射

日期：2026-11-21。分支：`codex/water-03-screen-reflections`。
基础：W2 提交 `db67a74a9244b81c809ce776a9c8567f17587039`。
[English notes](WATER_03_SCREEN_REFLECTIONS.md) · [水体路线图](WATER_ROADMAP.zh-CN.md)。

W3 加入 W1 场景快照的第一个消费者：由水面法线决定方向、有范围限制的
屏幕空间反射光线。实现及 CPU／离线／本机检查均已完成，并记录三种静态合成视角；
不声称 Minecraft／Iris 画面或性能已通过。

## 1. 控制与范围

| 控制 | 默认／可选值 | 用途 |
|---|---|---|
| `WATER_SCREEN_REFLECTIONS` | 1／0、1 | 开启场景反射追踪；关闭是 W2 对照路径 |
| `WATER_REFLECTION_STEPS` | 64／64、128 | 屏幕空间遍历的最大步数，不是世界距离 |
| 原有水面反射强度 | 不变 | 场景反射与可用天空回退的艺术强度 |

新控制位于水面反射强度之后。预设仍只控制七项，不覆盖这两个设置。
增加步数可能覆盖更多可见样本，也增加工作量；不会补出屏幕外几何体或保证命中。
目前没有 FPS 测量结论。

这是针对单层已捕获深度的屏幕空间光线追踪，不是硬件光追、体素追踪或路径追踪，
没有安装新后端。被遮挡表面、屏幕外物体、缺失层和未支持材质都不能凭空恢复。
W3 保留原生水面几何、覆盖、alpha 与已有水面法线控制。流动、折射和水下传输属于后续。

## 2. 配对输入与明确的遮挡保护

| 输入 | 职责 |
|---|---|
| `colortex5` RGBA16F | W1 在 deferred 雾调用前的照明后线性 RGB；alpha 表示样本有效性 |
| `colortex6` R32F | 与 RGB 配对的非线性深度，先重建后再比较视图深度 |
| `depthtex1` | 相同时刻的主要透明绘制前深度，用来发现未支持的前景遮挡 |

水面只读取快照，不写回它们。gbuffers 程序中的 colortex0–3 对应纹理图集，不能
从那里读取场景颜色。W1 的发布侧／清空约定在游戏观察前仍属于 Iris 集成假设。
[Iris 颜色缓冲](https://shaders.properties/current/reference/buffers/colortex/)、
[W1 时序与有效性说明](WATER_01_SNAPSHOT.zh-CN.md)。

无效快照不一定是空天空。W1 会拒绝手部及未知表面元数据，把快照深度设为 1，
但原 `depthtex1` 仍可能记录着前景。保护逻辑应在遇到未支持的遮挡时停止，不能
穿过它去反射后方物体。它不会提供新的可反射颜色：有效命中的颜色和深度仍取自
配对的 5／6。有效命中还要求有效性精确为 1、RGB 有限且非负并在半精度范围内，
且 `colortex6` 与 `depthtex1` 深度完全一致；缓冲尺寸也必须相同。
没有快照代表未命中，不能据此虚构几何体。深度名称只是捕获时刻的
简写，不证明之前所有绘制都完全不透明。
[Iris 深度概览](https://shaders.properties/current/reference/buffers/depthtex/)。

## 3. 有边界的透视正确追踪

约定的遍历范围为：

- 起点沿原法线偏移 0.01 个视图单位，采用单位反射方向，从 0.05 距离开始；排除起点投影像素的命中。
- 最长 64 个视图空间单位；透视除法前先在近平面裁剪。
- 二维像素网格遍历覆盖精度可分辨的穿越区间；预算按实际处理像素计数，最多 64 或 128 个。
- 使用透视正确的光线深度区间，与捕获表面的视图深度比较。
- 自适应视图深度容差：将一个像素内的光线深度跨度限制在基础 0.15、上限 0.5；检查有限性、有效性和未命中情况。

近平面从 `gbufferProjectionInverse` 重建，并在裁剪前向内留出
`max(0.0001, abs(nearZ)*0.0001)` 的余量，不另设一份相机参数。
投影与逆投影使用同一个 Iris 世界相机约定；文档明确手部路径有深度缩放例外。
W1 会保守排除后来变近、可能属于手部的深度。
[Iris 矩阵](https://shaders.properties/current/reference/uniforms/matrices/)。

屏幕步数和光线长度是两个独立上限：投影很长的光线可能先走完 64 像素，远未达到
64 个视图单位。视图单位是着色器坐标单位，不能在任意相机变换下直接当成真实米。
深度容差针对单层可见表面，不是测得的方块厚度或水深。过大会虚构命中，过小会漏细物体。

透视正确的遍历前进到下一个 x 或 y 网格边界，精确穿过角点时同时推进两轴。
屏幕长度不大于 max(0.0001, 4 * 2^-23 * maxBufferDimension) 像素的区间会在
读取纹理及预算计数前跳过。这是明确的浮点精度策略，避免几乎碰角的光线因极微小
区间而消耗不同预算：最大尺寸为 96 时下限是 0.0001 像素，4096 时约为 0.00195 像素。
硬循环上限为 256 次，包含跳过区间；64／128 选项只计算实际处理区间。
因此它覆盖可分辨网格区间，并非每个数学上非零的细缝或只碰角、面积为零的邻格。
有限深度采样仍不能保证每根亚像素细杆或轮廓都被捕获。自适应深度区间容许一部分
掠射深度变化，也可能增加错误命中，因此仍限制在 0.5 以内。近平面、遮挡和预算
用尽需要独立检查。

开发中的解析几何案例发现了早期只走主轴及固定 0.15 区间导致的遗漏。
完整网格区间和有上限的自适应容差针对这些原因改进，最终 CPU 与本机案例已在
下方注明的范围内通过；早期失败版本不能记为成功运行。
[McGuire 与 Mara 的原始算法论文](https://jcgt.org/published/0003/04/04/paper.pdf)。
论文中的历史性能数字不是 Aurora 的测量结果。

## 4. 可信度、菲涅耳与环境分别处理

命中可信度表示当前屏幕数据能在多大程度上支持一个候选结果，控制场景命中向原有
水面／天空结果的过渡。当前可信度是三个经验渐隐权重的乘积：屏幕边缘距离
0–8 像素、光线行程 48–64 个视图单位，以及所选步数预算的最后 25%。
它不是校准过的概率，也不是材质属性。菲涅耳描述界面随角度变化的反射权重。
可信度降低不能解释为水的物理反射率改变。
[介电质反射与透射](https://www.pbr-book.org/4ed/Reflection_Models/Dielectric_BSDF)。

局部场景命中被设计为独立于 `SKY_STYLE`、`SKY_BLEND` 和天空光。
这些设置控制解析天空回退，不决定洞内是否存在有效、受光的表面。
原有材质、混合、线性／调试、维度、相机浸水和原始朝上表面条件仍明确保留。
洞内没有可用环境回退时，未命中应保留已有水面观感，不引入明亮的室外天空。
回退仍是解析 M7 配色，不包含真实天空极光、光晕、日月盘或云。W1 不捕获后绘制云层，
所以仅加入 SSR 不会自动补齐这些天空成分。

候选反射替代对应的回退贡献，不再额外叠加一份满强度反射。W2 法线控制光线方向；
未分辨波纹的粗糙度和时间累积仍未实现。快照 RGB 是从原相机视角着色的，
后续加入与视角相关的高光后，即使命中正确，也需要额外处理反射来源的方向差异。

## 5. 明确保留的两项光学限制

**仍使用原生源 alpha 混合。** 普通混合满足
`输出 = alpha * 水面源颜色 + (1-alpha) * 背景`，所以放进源颜色的反射也会被 alpha
减弱。W3 不除以 alpha，不改变透明度，也不独立对背景施加物理透射。
带菲涅耳形状的源色仍是艺术近似。
以完全受支持、可信度为 1 的命中为例，合成测试的 alpha 0.55 与默认反射强度 0.35，
会把正视水面时的 F0 0.02 减为 0.00385 的反射系数；即使到掠射极限，在雾、色调
及其他条件之前也最多为 0.1925。因此俯视变化很细微，并不直接说明光线追踪失败。
[Iris 混合规则](https://shaders.properties/current/reference/shadersproperties/rendering/)。

**水面到命中点的大气雾暂未建模。** 快照位于 deferred 相机路径雾之前，不代表更早
所有贡献都完全没有雾。W3 不把命中点传进以相机为起点的雾函数，否则会计算一次
“相机到命中点”，再计算一次“相机到水面”，路径不正确。
原有后绘制雾仍只沿相机到水面应用一次。省略反射段可能让远处倒影过清楚，
这是临时限制，不是完整物理结果。未来还需明确艺术化 `FOG_START` 距离如何分配，
不能每次反弹都重新获得一段无雾区。
[分段透射率](https://www.pbr-book.org/4ed/Volume_Scattering/Transmittance)。

下一步 W4 接管反射／透射合成，定义衰减、折射、多层透明限制和雾的责任范围。
W3 增加场景信息，并不代表整个水体光学系统已经完成。下一步 W4 将分开共用
WaterParams／光学、水面数据采集与 composite 光学合成，让模拟和后处理保持各自
职责。W3 没有引入计算着色器波浪模拟、新水体 composite 阶段或 TAA。

使用一个浅水池和一个深水池，配石岸、彩色墙、细杆、玻璃、手持物及暗处有顶的入口。
每次记录坐标、相机／FOV／分辨率、纹理包、时间／天气、设置和硬件。
