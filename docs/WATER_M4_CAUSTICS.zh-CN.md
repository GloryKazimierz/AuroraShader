# 水底焦散

水面起伏会改变光进入水中的方向。相邻几束阳光在水底落得更近，那一小片就变亮；光束分开处就变暗。在浅水池里，这比整片水底叠一张发亮的纹理更容易看出深度。

在光影设置中开启 **水体光学** 和 **水底焦散**。选择白天的浅水、明亮的平底和倾斜俯视的角度，可以同时看到水底光纹和水面反光。调整 **焦散强度** 可比较同一位置的变化。

| 看哪个位置 | 光影怎么判断 |
|---|---|
| 阳光照到的水底 | 从阴影贴图读取顶层水面的法线和深度，沿折射光线寻找受光的水底，估算相邻光线落点的面积。 |
| 阴影或火把旁 | 只调整水底光照里来自太阳或月亮的份额。火把和环境光保留自己的亮度。 |
| 从岸上斜看 | 水底画面会因折射而移位。光纹使用被折射光线实际看到的那块水底的法线、颜色和直接光份额。 |
| 深水和远处 | 光进水和离开水底分别衰减一次。距离过远、深度不连续或不足以分辨波纹时，效果渐退。 |

水表面由阴影通道绘制。Iris 的透明地形阴影开关决定水是否进入这一步；普通地形阴影继续读取不透明的深度副本。焦散记录使用 16 位归一化格式，两个 2048 × 2048 纹理面的名义容量合计 64 MiB。8 位记录在测试中丢失微小斜率，随波面移动会出现错误的亮度跳变。
