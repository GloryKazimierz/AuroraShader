# AuroraShader 水管线

游戏内从光影设置首页选择 **水面 / 海岸（中）** 可以先看流动、水纹和日月高光。需要场景倒影及水下仰视效果时，选择 **水面 / 倒影（高）**。画质控制要做哪些计算，水色和清澈度控制一米水怎样改变光。

## 一帧如何形成

| 顺序 | 阶段 | 产物和用途 |
|---|---|---|
| 0 | `setup` → 每帧 `begin`、`begin1`、`begin2` | 频谱波启用时建立两层初始谱，每帧执行二维逆变换，再汇总坡度能量。水面与阴影共用坡度场，浪尖泡沫读取水平形变。 |
| 1 | `shadow` | 记录不透明遮挡。开启焦散时也记录阳光实际照到的顶层水面法线、深度和身份，用来推算水底受光。 |
| 2 | `prepare1` | 可选的接触涟漪历史。每帧更新玩家或坐骑确实接触水时留下的扰动。 |
| 3 | 不透明 `gbuffers` → `deferred` | 先处理普通地形与实体。保存透明物体出现前的场景辐亮度、匹配深度和直接光份额。该快照是折射和反射查询的来源。 |
| 4 | `deferred1` → `gbuffers_water` | 前者为场景倒影生成可选的粗深度界限。后者保留原生透明颜色，并记录可接管水面的法线、深度、局部光照和叠层信息。 |
| 5 | `composite` | 启用折射时，逐块验证可见水面和床面是否连续，边缘或玻璃造成的混合会使分块无效。 |
| 6 | `composite1` | 在确认的水面上计算折射、双程吸收和散射、反射及高光。焦散作用于实际水底的直接光，然后才衰减；泡沫最后覆盖水面。水下出口走相反介质方向的折射或全内反射。 |
| 7 | `composite2–5` → `final` | 提取亮部、半分辨率模糊。可选的[水面时域稳定](WATER_K_TEMPORAL.zh-CN.md)在合回当帧泛光之前执行。最终着色器做曝光、色调映射与显示编码。 |

Iris 在不透明绘制和透明绘制之间执行 deferred。这使得水面可以在屏幕上查找已经渲染的岸壁和水底。相机看不到的物体、被遮掉的界面、已经出屏的反射线索都有数据边界。[Iris 的渲染阶段](https://shaders.properties/current/reference/programs/deferred/) · [prepare 与阴影的先后](https://shaders.properties/current/reference/programs/prepare/)

## 谁持有哪些数据

| 附件 | 内容 | 尺寸与寿命 |
|---|---|---|
| 七张频谱自定义图像 | 两层 64² 波谱、行变换、波面、前后两次水平位移和坡度统计 | 共 514.06 KiB，与屏幕分辨率无关；初始谱持久，前后位移支持泡沫回溯 |
| 0、1、2 | 当前场景颜色、不透明几何法线、光照 | 全分辨率，当帧 |
| 3、4 | 泛光的中间结果 | 半分辨率，当帧 |
| 5、6、9 | 雾前不透明颜色、配对深度、直接光份额 | 全分辨率，当帧 |
| 7、8 | 水面法线与深度；透明叠层计数、方块光、天空光、可见出口标记 | 全分辨率，deferred 在透明物体之前重置 |
| 10 | 场景倒影的保守深度界限 | 宽高各 1/8，当帧 |
| 11 | 水面和床面高度的最小值、最大值 | 宽高各 1/8，仅启用折射时绘制 |
| 12 | 水专用跨帧颜色、几何深度与两像素重置标记 | 可选，全分辨率，跨帧；1080p 双缓冲约 63.3 MiB |
| 13、14 | 泡沫历史和重投影所需的数据 | 可选，全分辨率，跨帧 |
| 15 | 接触水纹历史 | 可选，16 × 2，跨帧 |
| shadowcolor0、shadowtex0/1 | 经确认的水面记录、含透明与仅不透明的两个阴影深度 | 焦散使用 2048² 阴影图 |

以上数字是纹理编号，与同一次绘制的颜色输出个数不同。水下出口复用 7 和 8。分块、泡沫历史和接触历史可以独立启用。[Iris 颜色附件与翻转规则](https://shaders.properties/current/reference/buffers/colortex/)

## 从哪个视角最容易看出问题

- **浅、深水池俯视**可以分辨水色来自深度还是表面着色。使用相同白色床面的十二组对照检查水体吸收。[色板](validation/WATER_MATERIALS_views.png)
- **贴水看夕阳、月亮和雨天**可以检查掠射高光的宽度和亮度，水面起伏应与灯光方向一致。[日月光照对照](validation/WATER_GLINT_views.png)
- **河坡、瀑布和乘船转弯**可以分辨水纹沿流向移动还是跟随镜头。[水流与扰动](WATER_CURRENTS.zh-CN.md)
- **斜看玻璃和岸壁紧挨水面的位置**可以检查哪些像素仍能正确找到水底，哪些应该保留原生透明颜色。[折射证据](WATER_M3_PLANAR.zh-CN.md)
- **水下抬头并慢慢出水**可以分别看到透射、全内反射与近裁剪缺少水面几何的边界。[可见出口的适用范围](WATER_M3B_UNDERWATER.zh-CN.md)

## 水线与屏外反射的观测边界

眼睛距水面一厘米时，近裁面可能已经穿过水面。CPU 几何参考使用同一帧的有限阴影片重建这几厘米内的水段。15 组测试中，完整覆盖的 26,640 个像素全部判对了水和空气；屋顶、玻璃、岸边或未覆盖的格子回到原生颜色。[几何对照与误差](validation/nearclip/NEARCLIP_REFERENCE.zh-CN.md)

镜头转动 1.5° 时，上一帧可见的反射物可能已经出屏。即使这个物体仍与阴影深度吻合，一块新出现的 20 厘米障碍也可能挡在反射光线中段。在本例中，真实首个交点从 6.40 米变为 6.10 米。这是保守回退的原因。[屏外遮挡反例及复现](validation/offscreen/OFFSCREEN_COVERAGE.zh-CN.md)
