# 有限近期视图反射：覆盖证据

这是独立几何研究，不是已安装的光影功能。[可执行参考](offscreen_history_reference.py)使用精确三维射线／方盒求交，[保留结果](OFFSCREEN_COUNTEREXAMPLE_v2.json)已通过。第二版明确相同的是**当前相机能见的几何**，不是全部真实间接光照。

相机在(0,2,4)，向下角度由24.5°变为26°，垂直视场50°。旧目标(2,2,−8)由上一帧UV.y0.98865移至当前1.02297，反射水点仍在0.64240处可见。新放的0.2米方盒位于射线上，八个角点全部在当前屏外。旧目标仍匹配当前光源深度，但真实反射先在6.10431米撞到新方盒，而非6.40312米处的旧目标。**只验证终点会接受错误结果。**

沿整段的精确光源查询能拒绝这件新增投影物，且这种精确查询强于有限阴影纹理。若障碍不在投影集合内，连这个参考也无法区分：旧样本、当前画面内几何、当前阴影几何都没有观察它。限制历史贡献只能控制影响，不能使可见性自动真实。

## 生产实验所需条件

- 区分完整检查后的出屏与步数耗尽、短投影线、无效数据、加速前缀未知。当前`WATER_TRACE_UNRESOLVED`把这些原因合并。
- 已知屋顶／交点、透明归属阻挡、多层水、旧颜色／深度／比例缺失、过期分配／帧、尺寸／维度／FOV变化和转镜切断都拒绝。
- 重投影实际旧三维点，匹配旧深度，并对照当前阴影几何；整个复用段都需处于覆盖内，阴影图外只能算未知。
- 必测离屏中间新障碍、移除终点、移动不投影物、光照／材质变化和镂空。有效终点不能覆盖中途阻挡。
- 时间回退若进入生产，仍应主动开启、只用一帧、限制贡献，并明确静态投影几何的覆盖限制。若要求保证无残影，必须硬拒绝或获得更多当前可见性数据。

当前`shadowEntities = false`意味着阴影图不完整。旧亮度还可能对光源／材质变化迟一帧。大幅转镜必须清除历史。
