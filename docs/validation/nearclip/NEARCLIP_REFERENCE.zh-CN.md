# 有限近裁水线：冻结CPU参考

此快照是几何原型，不是Minecraft渲染结果，也没有安装颜色改动。输入采用现有RGBA16水面阴影记录、配对D24前深度、独立不透明光源深度。真实有限水面／床面矩形、屋顶和玻璃方盒通过独立世界射线求交生成输入。

先用2×2片定位近水平顶面，再分别采样相机及近裁点附近的2×2片；两者必须一致，并通过重心坐标线段裁剪证明eye→near投影完全处于有限三角形并集。初始平面只负责寻找真实观测，不能把水面外推到已验证小片之外。此版最多三个不同2×2查询，包含初始定位。

几何法线来自深度重建；波浪光学法线不改变介质边界。所有透视射线共用眼点，但每个像素的近裁点不同；用带符号距离分类，并积分eye→near的真实水段。

有效条件：当帧水记录／深度配对；水位于有效不透明深度之前；几何朝上法线≥.995；四水点高度范围≤4毫米；平面残差≤2毫米；边长≤.5米；床面高度范围≤25毫米；水床间距≥8厘米；相机距已采样顶面≤5厘米；近裁点离歧义界面>0.1毫米；无原生透明归属阻挡。任何条件不满足均为UNKNOWN，必须保留原生颜色。

有限小片仍只是采样证据。完全落在所有阴影采样点之间的小孔无法由这些输入辨认，因此不能声称一般封闭水体或无混叠保证；原生光学接入必须保留这个边界。

## 实际结果

[CPU报告](NEARCLIP_CPU.json)：15组光源／眼高，共34,560个像素；26,640被接受，介质分类全部正确，5,624个真实被近裁交点。水段最大误差0.1075毫米。测试上限0.25毫米按当前最大消光系数0.384/米换算，对应小于1e−4透射相对误差。这是数值预算，不是宣称Minecraft真实毫米精度。

11项反例全部UNKNOWN：缺记录、深度不配对、仅不透明／底面、原生覆盖、屋顶、玻璃、床过近、岸边、水位阶差、床面阶差、低光源。

图中三行为光源，五列眼高依次−4、−1、0、+1、+4厘米。金色=空气，蓝色=水，灰色=UNKNOWN。约23%的查询因两个端点小片未覆盖中途格子而回退。下一版可有界遍历真实中间小片，不能把平面延伸过去填空。
